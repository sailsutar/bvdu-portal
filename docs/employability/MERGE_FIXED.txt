# Fixed package: one student input path + staff tools

## What changed vs earlier packs

1. Student skills come from existing **Placement profile** (DSA / C / DBMS / AI-ML 1–5).
2. On every placement profile **Save**, backend syncs into Employability S1 skills (no second student form).
3. **Employability input** is **staff-only** (assessments, next action, results, HITL).
4. **Employability Intelligence** remains the read-only dashboard.
